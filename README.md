# China Law Skills

一组用于 AI 助手（Claude Code / 豆包等支持 Agent Skills 的环境）的中国法律结构化技能。

## 包含的技能

| 目录 | 说明 |
|---|---|
| [`china-civil-code/`](./china-civil-code) | 《中华人民共和国民法典》（2021 年施行，七编 1260 条）：条文检索、构成要件、法律后果。 |
| [`china-labor-law/`](./china-labor-law) | 《劳动法》＋《劳动合同法》及六部配套法规：劳动合同、解除补偿、工时工资、工伤、劳务派遣、争议处理。 |

## 目录结构

```
china-law-skills/
├── china-civil-code/    # SKILL.md + chapters/ + glossary/patterns/cheatsheet
└── china-labor-law/
    ├── SKILL.md
    ├── chapters/        # 两部主法律，10 章
    ├── regulations/     # 6 部配套法规（仲裁、工伤、实施条例、年假、女职工、派遣）
    └── glossary/patterns/cheatsheet
```

每个技能以 `SKILL.md` 为入口，`chapters/` 为分章内容，并提供 `glossary.md`（术语表）、`patterns.md`（分析框架）、`cheatsheet.md`（速查表）。

### china-labor-law 配套法规（regulations/）
劳动争议调解仲裁法、工伤保险条例、劳动合同法实施条例、职工带薪年休假条例、女职工劳动保护特别规定、劳务派遣暂行规定。

## 安装

把需要的技能目录复制到 Agent Skills 目录即可（例如 `~/.claude/skills/` 或对应环境的用户技能目录）。

## 使用

加载技能后直接提问，例如：
- “被公司违法辞退能要多少赔偿？”
- “上下班途中发生交通事故算工伤吗？”
- “加班费和未休年假怎么算？”
- “合同成立的要件是什么？”

- 本仓库内容为基于中国现行法律、行政法规整理生成的结构化内容。根据《中华人民共和国著作权法》，法律、法规等官方文件本身不适用著作权法保护；技能内容为要件化、表格化的提炼整理，非原文复制。
