## 关键时间/数字
| 事项 | 标准 |
|---|---|
| 标准工时 | 每日8h、**每周40h**；每周至少休1日 |
| 加班上限 | 日≤1h（特殊3h）、**月≤36h** |
| 加班费 | 工作日**150%**、休息日**200%**、法定节假日**300%** |
| 年休假 | 工龄1–10年5天、10–20年10天、20年以上15天 |
| 书面合同 | 用工之日起**1个月内**订立 |
| 二倍工资 | 超1个月不满1年未签，最多**11个月** |
| 无固定期限 | 连续满**10年**、连续**两次**固定期限后续订等 |
| 试用期 | 合同3月–1年→1月；1–3年→2月；≥3年/无固定→6月；工资≥**80%** |
| 竞业限制 | 期限≤**2年**，须按月补偿 |
| 童工 | 不满**16周岁**禁止；未成年工16–18岁 |
| 基础产假 | 现行**98天**＋地方奖励假 |
| 仲裁时效 | 现行**1年**；不服裁决**15日**内起诉 |

## 解除情形与补偿
| 类型 | 条文 | 补偿 |
|---|---|---|
| 协商解除（单位提出） | 36 | N |
| 劳动者预告辞职 | 37 | 无 |
| 被迫解除（欠薪/未缴社保等） | 38 | N |
| 过失性辞退（违纪/失职/兼职/刑责） | 39 | 无 |
| 无过失性辞退（医疗期满/不胜任/客观变化） | 40 | N（未提前30日为N+1） |
| 经济性裁员（≥20人或10%） | 41 | N |
| 违法解除/终止 | 48、87 | **2N**（不再付N） |

## N 计算
- 每满1年=1个月工资；6个月以上按1年；不满6个月=半个月。
- 月工资=解除/终止前**12个月平均**。
- 高薪：超社平**3倍**按3倍封顶、年限≤**12年**。

## 禁止解除（第42条）
职业病未体检/疑似观察期、职业病或工伤丧劳、医疗期、女职工三期、本单位连续满**15年且距退休不足5年**。

## 五险
养老、医疗、工伤、失业、生育——强制参保，不得用补贴替代。

## 劳务派遣
- 派遣单位注册资本≥**200万**、须行政许可；劳动合同≥**2年**。
- 三性：临时性（≤6月）、辅助性、替代性；用工比例≤**10%**；同工同酬；不得收费/再派遣。

## 非全日制
日均≤**4h**、周累计≤**24h**；可口头、无试用期、随时终止无补偿；结算≤**15日**。

## 加付/赔偿责任
- 拖欠报酬/补偿逾期：加付**50%–100%**。
- 未签合同/不订无固定期限：**二倍工资**。
- 违法解除：**2N**。
- 派遣违法、招用未解除合同者：连带赔偿。
