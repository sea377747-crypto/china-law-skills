# 中国《劳动法》＋《劳动合同法》结构化技能

## 概述
本技能整合两部核心劳动法律：
- **《中华人民共和国劳动法》**：1994年通过，2009、2018年两次修正，1995年施行，13章107条——劳动领域一般法。
- **《中华人民共和国劳动合同法》**：2007年通过，2012年修正，2008年施行，8章98条——劳动合同特别法，劳动合同事项优先适用。

> 重要：部分劳动法原文标准已被后续行政法规更新，本技能以**现行有效标准**为准（如周工时40小时、基础产假98天、仲裁时效1年）。

## 何时使用
- 询问劳动合同、事实劳动关系、入职/离职、辞退、经济补偿或赔偿。
- 询问工时、加班、加班费、工资、最低工资、年休假。
- 询问工伤、社保、女职工/未成年工保护、劳务派遣、非全日制、集体合同。
- 询问劳动争议如何调解、仲裁、起诉。
- 不适用：公务员/参公管理人事关系、社会保险待遇核定的具体行政程序、个案裁判预测；不替代执业律师意见。

## 快速开始
1. 先判断问题主题（订立/解除/工时/派遣/争议等）。
2. 高频数字查 `cheatsheet.md`；术语查 `glossary.md`；分析框架查 `patterns.md`。
3. 深入具体制度读取对应章节；涉及下位法细化（仲裁、工伤、年假产假、派遣比例）查 `regulations/`。

## 如何使用（按场景）
- **被辞退/想离职** → patterns 模式3审查解除合法性 → ch04/ch05，确定 N、N+1 或 2N。
- **拖欠工资/加班费** → ch06 核算 → ch10 责任（支付令、加付赔偿金）。
- **没签合同** → ch02，主张二倍工资。
- **工伤/没缴社保** → ch08（工伤认定、补缴、被迫解除）。
- **劳务派遣/非全日制** → ch09，识别三性、比例与同工同酬。
- **维权流程** → ch10，协商→仲裁（前置、时效1年）→诉讼。

## 标准工作流
1. 识别问题类型并确认是否存在劳动关系。
2. 先查速查/术语/模式，再按需读取章节（不一次性加载全部）。
3. 结论标注条文号，区分"法律规定"与"分析判断"。
4. 涉补偿先算工龄与月工资；涉请求先查时效。
5. 事实不清处指出需补充的事实，不作臆断。

## 回答规范
- 先给结论，再列要件/依据，条文号写括号内。
- 数字、期间、比例与现行规定一致；注意地方差异（产假奖励假、最低工资、社平工资）。
- 说明本技能提供规则与分析，不替代律师意见、人社部门核定和法院裁判。
