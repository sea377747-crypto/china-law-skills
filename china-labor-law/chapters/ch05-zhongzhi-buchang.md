# 劳动合同的终止与经济补偿（劳动合同法第44–50条）

## 核心要义
终止是因法定情形使合同关系消灭（不同于解除）。掌握：终止情形、合同续延、**经济补偿 N 的计算**、违法解除/终止的**赔偿金 2N**、离职交接与证明。

## 一、劳动合同终止情形（第44条）
1. 合同期满；
2. 劳动者开始依法享受**基本养老保险待遇**；
3. 劳动者死亡，或被法院宣告死亡/失踪；
4. 用人单位被依法宣告**破产**；
5. 用人单位被吊销营业执照、责令关闭、撤销或决定提前解散；
6. 法定其他情形。

**合同续延（第45条）**：期满但有第42条情形之一的，应续延至相应情形消失时终止；其中患职业病/因工负伤丧失或部分丧失劳动能力者，合同终止按国家工伤保险规定执行。

## 二、经济补偿（第46–47条，重点）
**应支付经济补偿的情形（第46条）**：
1. 劳动者依第38条被迫解除；
2. 用人单位提出并协商一致解除（第36条）；
3. 单位依第40条无过失性辞退；
4. 单位依第41条第1款裁员；
5. **固定期限合同期满终止**——除单位维持或提高约定条件续订、劳动者不同意续订外，应补偿；
6. 依第44条第4项（破产）、第5项（吊销/关闭/撤销/解散）终止；
7. 法定其他情形。

**N 的计算（第47条，核心数字）**：
- 按在本单位工作年限，**每满1年支付1个月工资**；
- **6个月以上不满1年按1年算；不满6个月支付半个月工资**。
- **月工资**：合同解除或终止前**12个月的平均工资**。
- **高薪封顶**：月工资高于本地区上年度职工月平均工资**3倍**的，按**3倍**数额支付，且支付年限**最高不超过12年**。

## 三、违法解除/终止的赔偿金（第48、87条，2N）
- 用人单位违法解除或终止：
  - 劳动者要求**继续履行**的，应当继续履行；
  - 劳动者不要求继续履行或已不能继续履行的，应按第47条经济补偿标准的**二倍支付赔偿金（2N）**。
- **2N 与 N 不并用**：支付了赔偿金（2N）的，不再另行支付经济补偿（N）。
- 第40条无过失性辞退未提前30日通知的，额外付1个月工资（"代通知金"，即 N+1）。

## 四、离职手续（第49–50条）
- 单位应在解除/终止时**出具书面证明**，并在**15日内**办理档案和社会保险关系转移。
- 劳动者按约定办理工作交接；应支付经济补偿的，在**办结交接时**支付。
- 已解除/终止的合同文本，单位至少保存**2年**备查。
- 社保关系跨地区转移接续（第49条）。

## 补偿/赔偿对照
| 情形 | 金额 |
|---|---|
| 合法解除/终止且第46条情形 | **N** |
| 第40条未提前30日通知 | **N + 1**（代通知金） |
| 违法解除/终止 | **2N**（不再付N） |
| 试用期违法解除 | 视情继续履行或2N |

## 典型示例（study）
- 员工在公司工作3年7个月，月均工资1万元，公司因经营困难合法裁员 → 工作年限按4年算，经济补偿 **4万元（N=4）**（第47条）。
- 公司无正当理由辞退工作2年的员工，员工不要求继续履行 → 属违法解除，应支付 **2N=4个月工资**，不再另付经济补偿（第87条）。
- 合同到期，公司维持原薪资续订而员工不同意 → 合同终止，**无需**经济补偿（第46条第5项）；若公司降薪续订员工不同意，则应支付N。

## 关键提示
1. N 按工龄：满1年1个月、满6个月按1年、不满6个月半个月；月工资取前12个月平均。
2. 高薪（超社平3倍）按3倍封顶、年限最多12年。
3. 违法解除：能继续履行则继续履行，否则2N；2N 吸收 N。
4. 固定期限合同到期，单位降条件续订导致不成也要给N；单位维持/提高条件而员工不续则无N。
5. 离职15日内转档案社保、办结交接时付补偿、出具书面证明。
