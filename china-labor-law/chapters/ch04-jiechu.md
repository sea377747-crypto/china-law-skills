# 劳动合同的解除（劳动合同法第36–43条；劳动法第24–32条）

## 核心要义
解除分**协商解除、劳动者解除、用人单位解除**三条线。用人单位单方解除受严格限制，须符合法定情形、履行工会程序，否则构成违法解除（2N，见 ch05）。

## 一、协商解除（第36条）
双方协商一致可解除。**由用人单位提出**并协商一致解除的，应付经济补偿（第46条第2项）；劳动者主动提出的，无补偿。

## 二、劳动者解除
**预告辞职（第37条）**：提前**30日**书面通知；试用期内提前**3日**通知，可解除（无补偿）。
**被迫即时解除（第38条，单位有过错，可主张经济补偿）**：
1. 未按约定提供劳动保护或劳动条件；
2. **未及时足额支付劳动报酬**；
3. **未依法缴纳社会保险费**；
4. 规章制度违法损害劳动者权益；
5. 因第26条第1款致合同无效；
6. 法定其他情形。
- 以暴力、威胁、非法限制人身自由强迫劳动，或违章指挥、强令冒险作业危及人身安全的，可**立即解除，不需事先告知**。

## 三、用人单位解除
**过失性辞退（第39条，无须补偿，可立即解除）**：
1. 试用期被证明不符合录用条件；
2. **严重违反规章制度**；
3. 严重失职、营私舞弊给单位造成重大损害；
4. 同时与其他单位建立劳动关系，对完成本单位任务造成严重影响，或经提出拒不改正；
5. 因第26条第1款第1项（欺诈胁迫乘人之危）致合同无效；
6. 被依法追究刑事责任。

**无过失性辞退（第40条，须补偿，提前30日书面通知或额外付1个月工资——"N+1/代通知金"）**：
1. 患病或非因工负伤，**医疗期满后**不能从事原工作也不能从事另行安排的工作；
2. 不能胜任工作，经**培训或调岗**仍不能胜任；
3. 订约时客观情况发生重大变化致合同无法履行，经协商未能变更。

**经济性裁员（第41条）**：
- 条件：裁减**20人以上**或不足20人但占职工总数**10%以上**；提前30日向工会或全体职工说明、听取意见，方案向劳动行政部门**报告**后可裁。
- 适用：依破产法重整；生产经营严重困难；转产/重大技术革新/经营方式调整，变更合同后仍需裁；其他客观经济情况重大变化致合同无法履行。
- **优先留用**：订较长期固定期限合同者；订无固定期限合同者；家庭无其他就业人员、有需扶养老人或未成年人者。
- 6个月内重新招用，应通知被裁人员并在同等条件优先招用。

## 四、禁止解除情形（第42条，重点）
劳动者有下列情形，单位**不得依第40、41条解除**：
1. 接触职业病危害作业未做离岗前体检，或疑似职业病在诊断/医学观察期间；
2. 在本单位患职业病或因工负伤被确认丧失/部分丧失劳动能力；
3. 患病或非因工负伤在规定**医疗期**内；
4. 女职工在**孕期、产期、哺乳期**；
5. 在本单位连续工作满**15年**且距法定退休年龄不足**5年**；
6. 法定其他情形。

## 五、工会程序（第43条）
用人单位单方解除，应**事先将理由通知工会**；违反法律法规或合同的，工会有权要求纠正，单位应研究并书面通知工会结果。未通知工会可能被认定违法解除。

## 解除情形对照速查
| 解除类型 | 谁提出 | 通知要求 | 经济补偿 |
|---|---|---|---|
| 协商解除 | 单位提出 | — | 有 |
| 劳动者预告辞职 | 劳动者 | 30日（试用3日） | 无 |
| 被迫解除（第38条） | 劳动者 | 可立即（危及安全） | 有 |
| 过失性辞退（第39条） | 单位 | 可立即 | 无 |
| 无过失性辞退（第40条） | 单位 | 30日或+1个月工资 | 有 |
| 经济性裁员（第41条） | 单位 | 30日说明+报告 | 有 |

## 典型示例（study）
- 员工因公司连续3个月拖欠工资而辞职 → 属第38条被迫解除，公司除补发工资外还应支付**经济补偿（N）**。
- 员工处于哺乳期，公司以"不能胜任工作"为由依第40条解除 → 违反第42条禁止解除，构成**违法解除**，员工可要求继续履行或主张2N（见 ch05）。
- 公司以"严重违反规章制度"辞退，但规章制度未经民主程序、无证据证明违纪 → 解除依据不成立，属违法解除。

## 关键提示
1. 单位单方解除须"法定情形 + 证据 + 工会程序"，缺一即可能违法。
2. 第39条（过失）无补偿、第40条（无过失）N或N+1、第41条（裁员）N。
3. 第42条六类人不得用第40、41条解除（但有第39条情形仍可解除）。
4. 劳动者被迫解除（第38条）也能拿经济补偿。
