# 第一编 总则（第1–204条）

## 核心要义
总则规定全部民事活动的通用规则：**基本原则 → 主体（自然人/法人/非法人组织）→ 民事权利 → 民事法律行为 → 代理 → 民事责任 → 诉讼时效与期间**。处理任何具体纠纷先回到本编确定主体资格、行为效力与时效。

## 基本原则（第3–9条，判断民事活动合法性的总阀门）
| 原则 | 条文 | 适用要点 |
|---|---|---|
| 权益受保护 | 第3条 | 人身、财产及其他合法权益不得侵犯 |
| 平等 | 第4条 | 主体法律地位一律平等 |
| 自愿 | 第5条 | 按自己意思设立/变更/终止法律关系 |
| 公平 | 第6条 | 合理确定权利义务（显失公平可撤销） |
| 诚信 | 第7条 | 秉持诚实、恪守承诺（帝王条款） |
| 守法与公序良俗 | 第8条 | 不得违法、不得违背公序良俗 |
| 绿色 | 第9条 | 节约资源、保护生态环境 |

**法源顺序（第10条）**：法律 → 习惯（不得违背公序良俗）；特别法优先（第11条）；域内活动原则上适用中国法（第12条）。

## 自然人
**权利能力（第13–16条）**：始于出生、终于死亡，一律平等；胎儿在**继承、接受赠与**等利益保护时视为有权利能力，但娩出时为死体的自始不存在。出生/死亡时间以出生证明、死亡证明 → 户籍登记 → 其他证据为准（第15条）。

**行为能力（年龄与辨认能力双重标准）**：
| 类型 | 年龄/状态 | 行为效力 |
|---|---|---|
| 完全 | ≥18周岁；16–18周岁以自己劳动收入为主要生活来源（视为） | 独立实施，有效 |
| 限制 | 8周岁以上未成年人；不能完全辨认行为的成年人 | 纯获利益、与年龄智力相适应的有效；其余经法定代理人同意/追认 |
| 无 | 不满8周岁；不能辨认行为的成年人 | 独立实施无效，由法定代理人代理 |

**监护（第26–39条）**：父母是未成年子女法定监护人并负抚养义务；成年人监护顺序为**配偶 → 父母子女 → 其他近亲属 → 其他经同意的个人/组织**。可遗嘱指定（第29条）、协议确定（第30条）、居委会/村委会/民政或法院指定（第31条）。完全民事行为能力成年人可书面**意定监护**（第33条）。履职原则为"最有利于被监护人"，除为被监护人利益外不得处分其财产（第35条）。法定情形可撤销监护资格，但抚养/赡养/扶养义务不免除（第36–37条）。

**宣告失踪与宣告死亡**：
- 宣告失踪：下落不明满**2年**，财产由代管人管理（第40–45条）。
- 宣告死亡：下落不明满**4年**；因意外事件满**2年**（经证明不可能生存的不受2年限制）（第46条）。同批申请中既有人申请失踪又有人申请死亡、符合死亡条件的，应宣告死亡（第47条）。
- 撤销后果：婚姻关系自撤销日自行恢复（配偶再婚或书面声明不愿恢复的除外，第51条）；依继承取得财产者应返还，无法返还的适当补偿（第53条）。

**两户（第54–56条）**：个体工商户（可起字号）、农村承包经营户；个体工商户债务个人经营以个人财产、家庭经营以家庭财产承担，无法区分的以家庭财产承担。

## 法人与非法人组织
**法人（第57–101条）**：依法独立享有权利、承担义务，以**全部财产独立承担责任**（第60条）。法定代表人以法人名义活动的后果由法人承受，章程对代表权的限制不得对抗善意相对人（第61条）。
- **营利法人**（第76–86条）：公司等，须登记，营业执照签发日为成立日。出资人滥用法人独立地位和有限责任逃债、严重损害债权人利益的，承担**连带责任（法人人格否认）**（第83条第2款）。
- **非营利法人**（第87–95条）：事业单位、社会团体、基金会、社会服务机构；终止时不得向出资人分配剩余财产。
- **特别法人**（第96–101条）：机关法人、农村集体经济组织法人、合作经济组织法人、居/村委会法人。
- 合并由存续法人承继；分立原则上连带债权债务（第67条）；解散须清算，清算期间不得从事无关活动（第68–72条）。

**非法人组织（第102–108条）**：个人独资企业、合伙企业、不具法人资格的专业服务机构；可自己名义活动，但财产不足清偿时出资人/设立人承担**无限责任**。

## 民事权利体系（第109–132条）
人身权（人身自由、人格尊严、生命/身体/健康/姓名/肖像/名誉/荣誉/隐私/婚姻自主、个人信息）；财产权——**物权**（所有权、用益物权、担保物权，种类与内容法定，第116条）、**债权**（合同、侵权、无因管理、不当得利，第118条）、知识产权（第123条八类客体）、继承权、股权及投资性权利；数据、网络虚拟财产依法保护（第127条）。行使权利不得滥用损害国家、社会公共利益或他人合法权益（第132条，禁止权利滥用）。

## 民事法律行为（第133–160条）
**有效三要件（第143条）**：①行为人有相应行为能力；②意思表示真实；③不违反法律行政法规强制性规定、不违背公序良俗。

**效力瑕疵图谱**：
| 效力 | 情形 | 条文 |
|---|---|---|
| 无效 | 无行为能力人实施；虚假意思表示（通谋虚伪）；违反强制性规定（但该规定不导致无效的除外）；违背公序良俗；恶意串通损害他人 | 144、146、153、154 |
| 可撤销 | 重大误解；欺诈（含第三人欺诈且相对人知情）；胁迫；显失公平（利用危困、缺乏判断力） | 147–151 |
| 效力待定 | 限制行为能力人超出能力范围的行为；无权代理 | 145、171 |

**撤销权期间（第152条）**：知道或应知撤销事由起**1年**（重大误解为**90日**；受胁迫自胁迫终止起1年）；自行为发生起**5年**未行使则消灭。
无效/被撤销自始无约束力（第155条），部分无效不影响其他部分（第156条）；后果为返还财产→折价补偿→按过错赔偿（第157条）。
可附条件（不正当阻止视为成就、不正当促成视为不成就，第159条）、可附期限（第158、160条）。

**意思表示生效（第137–139条）**：对话方式——知道内容时；非对话——到达时；数据电文进入指定系统时；无相对人——表示完成时；公告——发布时。沉默仅在法律规定、当事人约定或符合交易习惯时才视为意思表示（第140条）。

## 代理（第161–175条）
- 委托代理与法定代理（第163条）；代理人在权限内以被代理人名义行为，对被代理人发生效力（第162条）。
- **无权代理（第171条）**：没有代理权、超越代理权或终止后仍实施，未经追认对被代理人不生效；相对人可催告**30日**内追认，未作表示视为拒绝；追认前善意相对人可撤销。
- **表见代理（第172条）**：相对人有理由相信行为人有代理权的，代理行为**有效**（保护善意相对人）。
- 自己代理、双方代理须经被代理人同意/追认（第168条）；转委托原则上须经同意，紧急情况除外（第169条）；职务代理在职权范围内有效，内部限制不得对抗善意相对人（第170条）。

## 民事责任（第176–187条）
- **按份责任**：能确定份额的各自承担，难确定的平均（第177条）。**连带责任**：权利人可请求部分或全部连带责任人承担，超份额清偿者可追偿；连带由法律规定或当事人约定（第178条）。
- 责任方式11种（第179条）：停止侵害、排除妨碍、消除危险、返还财产、恢复原状、修理重作更换、继续履行、赔偿损失、支付违约金、消除影响恢复名誉、赔礼道歉；可单独或合并适用；法律规定惩罚性赔偿的从其规定。
- **免责/减责事由**：不可抗力（不能预见、避免、克服，第180条）；正当防卫（超限适当担责，第181条）；紧急避险（自然原因引起的不担责可补偿，措施不当或超限适当担责，第182条）；见义勇为受损由侵权人担责、受益人可补偿（第183条）；**自愿紧急救助造成受助人损害的，救助人不担责（好人条款，第184条）**。
- 违约与侵权竞合时受损害方可**选择**请求（第186条）；财产不足时民事责任优先于行政、刑事责任（第187条）。

## 诉讼时效与期间（第188–204条）
- 普通时效**3年**，自知道或应知权利受损及义务人起算；最长保护期**20年**（特殊情况可申请延长）（第188条）。
- **法院不得主动适用**诉讼时效（第193条）；届满后义务人同意履行的不得再抗辩，自愿履行的不得请求返还（第192条）。
- **中止**：最后6个月内出现不可抗力、无代理人/代理人死亡丧失能力、未确定继承人或遗产管理人、被控制等障碍，自消除之日起满**6个月**届满（第194条）。
- **中断**：权利人提出履行请求、义务人同意履行、提起诉讼或仲裁等，重新计算（第195条）。
- **不适用时效**：停止侵害/排除妨碍/消除危险；不动产及登记动产返还财产；抚养费/赡养费/扶养费（第196条）。
- 期间计算：开始当日不计入、自次日起；按年月的到期月对应日为最后一日，无对应日的月末日；最后一日为法定休假日的顺延至次日（第200–203条）。

## 典型示例（效力判断，study）
10周岁儿童用压岁钱购买20元文具 → 与年龄智力相适应，**有效**；若用父母手机打赏主播5万元 → 超出能力范围，**效力待定**，法定代理人拒绝追认则无效，可请求返还（第145条）。商家明知对方误把镀金当纯金仍低价收购 → 重大误解/欺诈，受损方可在知道起90日/1年内请求**撤销**，撤销后返还、折价补偿（第147、152、157条）。

## 关键提示
1. 判断合同/行为先过第143条三要件，再对号入座无效/可撤销/效力待定。
2. 年龄节点：8周岁（无/限制分界）、16周岁（劳动收入视为完全）、18周岁（成年）。
3. 期间节点：撤销权1年（误解90日、最长5年）；时效3年（最长20年）；催告追认30日；中止缓冲6个月。
4. 善意相对人在表见代理、代表人越权、决议被撤销等场景均受保护。
