# 第二编 物权（二）：用益物权后半、担保物权与占有（第345–462条）

## 核心要义
本部分掌握用益物权五类（建设用地、宅基地、居住权、地役权＋土地承包）与担保物权三类（抵押、质押、留置）的**设立要件与优先受偿顺序**，以及占有的保护规则。

## 建设用地使用权（第345–361条）
- 可在地表、地上、地下**分别设立**（第345条）；设立方式为**出让**与**划拨**，经营性用地及有两个以上意向者须招标拍卖等公开竞价，严格限制划拨（第347条）。
- **自登记时设立**（第349条）；建筑物所有权原则上"房地一体"（第352、356–357条）。
- 使用权人可转让、互换、出资、赠与、抵押，约定期限不得超过剩余期限（第353–354条）。
- **续期（第359条）**：住宅用地届满**自动续期**（费用依法缴纳或减免）；非住宅依法办理。
- 期限届满前因公共利益提前收回的，对房屋等补偿并退还相应出让金（第358条）。

## 宅基地使用权（第362–365条）
对集体所有土地享有占有、使用权，可建造住宅及附属设施；取得、行使、转让适用土地管理法规；因自然灾害等灭失的，对失去宅基地的村民应**重新分配**。

## 居住权（第366–371条，新增用益物权）
- 为满足生活居住，对他人住宅占有、使用；**原则上无偿**，书面合同，**自登记时设立**（第368条）。
- **不得转让、继承**；设立居住权的住宅原则上不得出租（另有约定除外）（第369条）。
- 期限届满或权利人死亡即消灭，须注销登记；可以遗嘱方式设立（第370–371条）。

## 地役权（第372–385条）
- 利用他人不动产（供役地）以提高自己不动产（需役地）效益（第372条）；**自合同生效时设立**，未登记不得对抗善意第三人（第374条）。
- **从属性**：不得单独转让/抵押，随需役地用益物权一并转让（第380–381条）；期限不得超过所依附用益物权的剩余期限（第377条）。
- 已设立用益物权的土地，未经用益物权人同意，所有权人不得再设地役权（第379条）。
- **解除（第384条）**：滥用地役权；有偿利用经**两次催告**仍不付费。

## 担保物权一般规定（第386–393条）
- 本质：债务人不履行到期债务或约定情形时，就担保财产**优先受偿**（第386条）。
- **从属性（第388条）**：担保合同是主债权债务合同的从合同，主合同无效则担保合同无效（法律另有规定除外）；无效后各方按过错担责。
- **担保范围（第389条）**：主债权及利息、违约金、损害赔偿金、保管担保财产和实现担保物权的费用（可另约定）。
- **物上代位（第390条）**：担保财产毁损灭失被征收的，可就保险金/赔偿金/补偿金优先受偿或提存。
- **物保与人保并存（第392条，重点）**：有约定从约定；无约定，**债务人自己提供物保的，先就该物保实现**；第三人提供物保的，债权人可选择就物保实现或请求保证人担责；第三人担责后可向债务人追偿。
- 消灭原因：主债权消灭、担保物权实现、债权人放弃等（第393条）。

## 抵押权（第394–424条）
**特征**：不转移财产占有（第394条）。
| 事项 | 规则 | 条文 |
|---|---|---|
| 可抵押财产 | 建筑物及附着物、建设用地使用权、海域使用权、生产设备/原材料/半成品/产品、在建建筑物船舶航空器、交通运输工具等（法不禁止即可） | 395 |
| 浮动抵押 | 企业/个体户/农业经营者现有及将有的动产抵押，就抵押财产**确定时**的动产优先受偿 | 396、411 |
| 不得抵押 | 土地所有权；宅基地等集体土地使用权（法定除外）；公益法人的公益设施；权属不明/有争议；被查封扣押监管财产 | 399 |
| 房地一体 | 抵押建筑物则建设用地使用权一并抵押，反之亦然，未一并的视为一并抵押 | 397 |
| 不动产抵押设立 | 自**登记**时设立（建筑物、建设用地使用权、海域使用权、在建建筑物） | 402 |
| 动产抵押设立 | 自抵押**合同生效**时设立，未登记不得对抗善意第三人；且不得对抗正常经营中付合理价款并取得抵押财产的买受人 | 403、404 |
| 流押禁止 | 届满前约定到期不还财产归债权人所有的，只能**依法优先受偿**（不直接取得所有权） | 401 |
| 抵押财产转让 | 抵押期间可转让（另有约定除外），抵押权不受影响，应通知抵押权人，价款可提前清偿或提存 | 406 |
| 先租后抵 | 抵押前已出租并转移占有的，原租赁关系不受影响 | 405 |

**实现与清偿顺序**：
- 方式：协议折价或拍卖、变卖，不成则请求法院；折价变卖参照市价（第410条）。
- **同一财产多重抵押（第414条）**：已登记的按**登记时间先后**；登记的先于未登记；均未登记按**债权比例**清偿。
- **抵押与质权并存（第415条）**：按登记、交付的时间先后。
- **价款抵押权超级优先（第416条）**：为担保抵押物价款，标的物交付后**10日内**办抵押登记的，优先于买受人的其他担保物权人（但留置权人除外）。
- 建设用地抵押后**新增建筑物**不属抵押财产，可一并处分但无权就新增部分价款优先受偿（第417条）。
- 抵押权应在**主债权诉讼时效期间**行使，逾期法院不保护（第419条）。

**最高额抵押（第420–424条）**：对一定期间内连续发生的债权，在最高债权额限度内担保；债权确定前部分债权转让的，最高额抵押权原则上不随之转让；约定不明的，自设立满**2年**可请求确定债权（第423条）。

## 质权（第425–446条）
**动产质权**：将动产**移交债权人占有**，**自交付时设立**（第425、429条）；禁止转让的动产不得出质（第426条）；**流质禁止**（同流押逻辑，第428条）；质权人妥善保管，擅自使用处分或转质致损要赔偿（第431–434条）；债务清偿后应返还（第436条）。

**权利质权（第440–446条）**：可出质——汇票/本票/支票、债券/存款单、仓单/提单、可转让基金份额/股权、可转让知识产权财产权、现有及将有应收账款等。
| 标的 | 设立时点 |
|---|---|
| 票据、债券、存款单、仓单、提单 | 权利凭证**交付**时；无凭证的**登记**时（第441条） |
| 基金份额、股权 | **登记**时（第443条） |
| 知识产权财产权 | **登记**时（第444条） |
| 应收账款 | **登记**时（第445条） |
出质后基金份额/股权、知识产权、应收账款原则上不得转让/许可，经协商同意的，所得价款提前清偿或提存。

## 留置权（第447–457条，法定担保物权）
- 债权人已**合法占有**债务人动产，债务人不履行到期债务可留置并优先受偿（第447条）。
- 留置动产应与债权属**同一法律关系**，但**企业之间留置除外**（第448条）。
- 可分物的留置价值应相当于债务金额（第450条）。
- 应给债务人**60日以上**履行期（鲜活易腐等除外），逾期可折价或拍卖变卖（第453条）。
- **同一动产上抵押/质押后又被留置的，留置权人最优先**（第456条）。
- 丧失占有或债务人另行提供担保被接受的，留置权消灭（第457条）。

## 占有（第458–462条）
- **恶意占有人**因使用致占有物损害的应赔偿（第459条）；权利人请求返还原物及孳息，但应支付**善意占有人**支出的必要维护费用（第460条）。
- 占有物毁损灭失的，占有人应返还保险金/赔偿金/补偿金，不足部分由**恶意占有人**赔偿（第461条）。
- 占有被侵占可请求返还原物，被妨害可请求排除妨害/消除危险；**占有人返还原物请求权自侵占发生起1年**内不行使消灭（第462条）。

## 典型示例（study）
甲以设备为乙银行设定动产抵押（合同生效、未登记），后又把设备出质给丙并交付，再因欠丁修理费被丁留置。设备变价款的受偿：**丁（留置权）最优先**（第456条）；乙与丙之间，质权因交付（公示）在先/在后按第415条以"登记、交付时间先后"比较——乙未登记不能对抗，丙已受领交付；最终丁→丙→乙（乙未登记不得对抗善意第三人，第403条）。

## 关键提示
1. 抵押不转移占有、质押转移占有、留置基于合法占有而法定产生。
2. 设立时点：不动产抵押与权利质权多为"登记"，动产抵押"合同生效"，动产质权"交付"。
3. 清偿顺位口诀：留置 > 价款超级优先权（10日内登记）> 已登记/已交付（按时间先后）> 未登记（按债权比例）。
4. 流押/流质条款不产生所有权转移效力，但不影响优先受偿。
5. 居住权登记设立、不得转让继承；地役权合同生效设立、登记对抗。
