# 第七编 侵权责任（第1164–1258条）

## 核心要义
侵权责任以**损害赔偿**为核心。先定**归责原则**（过错／过错推定／无过错），再看责任主体与特殊侵权类型。

## 一、归责原则（第1165–1166条）
| 原则 | 内涵 | 举证 |
|---|---|---|
| 过错责任（一般） | 因过错侵害他人民事权益造成损害（第1165条第1款） | 受害人证明行为人有过错 |
| 过错推定 | 依法推定有过错，不能证明无过错即担责（第2款） | **行为人自证无过错** |
| 无过错责任 | 不论有无过错，法律规定应担责（第1166条） | 受害人无须证明过错，行为人须证明法定免责事由 |

侵权危及人身财产安全的，可请求**停止侵害、排除妨碍、消除危险**（第1167条，预防性责任）。

## 二、多数人侵权（第1168–1172条）
| 类型 | 要件 | 责任 | 条文 |
|---|---|---|---|
| 共同侵权 | 二人以上共同实施 | 连带 | 1168 |
| 教唆帮助 | 教唆帮助他人（教唆帮助无/限制行为能力人的，教唆帮助人担责，监护人未尽职责相应责任） | 连带 | 1169 |
| 共同危险行为 | 数人行为危及安全，不能确定具体侵权人 | 连带（能确定具体侵权人的除外） | 1170 |
| 分别侵权（累积因果） | 分别实施、**每个人行为都足以造成全部损害** | 连带 | 1171 |
| 分别侵权（部分因果） | 分别实施造成同一损害 | 能确定份额各自担责，难确定平均 | 1172 |

## 三、免责与减责（第1173–1178条）
- **过失相抵（第1173条）**：被侵权人对损害发生或扩大有过错，可减轻。
- **受害人故意（第1174条）**：损害完全因受害人故意造成，行为人不担责。
- 第三人造成损害由第三人担责（第1175条）。
- **自甘风险（第1176条）**：自愿参加有一定风险的文体活动，因其他参加者受损，不得请求其担责；但其他参加者有**故意或重大过失**除外（组织者责任另按安保义务）。
- **自助行为（第1177条）**：合法权益受侵害、情况紧迫不能及时获国家机关保护，可在必要范围内扣留侵权人财物等，但应**立即请求国家机关处理**；措施不当造成损害担责。

## 四、损害赔偿（第1179–1187条）
- **人身损害（第1179条）**：医疗费、护理费、交通费、营养费、住院伙食补助费、误工费；致残另赔辅助器具费、**残疾赔偿金**；致死另赔丧葬费、**死亡赔偿金**。同一侵权致多人死亡可按**相同数额**确定死亡赔偿金（同命同价，第1180条）。
- 被侵权人死亡，其**近亲属**有权请求；支付医疗费丧葬费者可请求偿还（第1181条）。
- 人身权益造成财产损失，按被侵权人损失或侵权人获益赔偿，难定的由法院确定（第1182条）。
- **精神损害赔偿（第1183条）**：侵害自然人人身权益造成**严重精神损害**；因故意或重大过失侵害自然人**具有人身意义的特定物**造成严重精神损害。
- 财产损失按**损失发生时市场价格**计算（第1184条）；故意侵害知识产权情节严重可请求**惩罚性赔偿**（第1185条）。
- **公平分担（第1186条）**：双方对损害发生都无过错，依法由双方分担。赔偿原则上一次性支付，分期须提供担保（第1187条）。

## 五、责任主体的特殊规定（第1188–1201条）
| 主体 | 规则 | 条文 |
|---|---|---|
| 监护人 | 无/限制行为能力人致损，监护人承担（无过错）；**尽到监护职责可减轻**；本人有财产先从本人财产支付 | 1188 |
| 委托监护 | 监护人担责，受托人有过错相应责任 | 1189 |
| 暂时无意识 | 有过错担责、无过错适当补偿；**醉酒、滥用麻醉/精神药品致损应担责** | 1190 |
| 用人单位 | 工作人员执行工作任务致损单位担责（无过错），事后向有故意/重大过失者追偿；劳务派遣由**用工单位**担责，派遣单位有过错相应责任 | 1191 |
| 个人劳务 | 提供劳务方致损由接受方担责（可追偿）；提供劳务方自身受损按双方过错；第三人致害可请求第三人或接受方补偿 | 1192 |
| 承揽 | 定作人不担责，但对**定作、指示、选任**有过错相应责任 | 1193 |

**网络侵权（第1194–1197条）**：
- 用户、网络服务提供者利用网络侵权担责（第1194条）。
- **"通知—删除"规则（第1195条）**：权利人通知（含初步证据及身份信息），提供者应转送用户并采取删除/屏蔽/断链等必要措施；未及时采取就**损害扩大**部分与用户连带；错误通知致损应赔偿。
- **反通知（第1196条）**：用户可提交不侵权声明，提供者转送权利人，合理期限内未收到投诉/起诉通知应及时终止措施。
- 提供者**知道或应知**用户侵权未采取措施的连带（第1197条）。

**安全保障义务（第1198条）**：宾馆、商场、银行、车站、机场、场馆、娱乐场所等经营者/管理者及群众活动组织者未尽安保义务担责；第三人致害由第三人担责，安保义务人未尽义务承担**补充责任**（可追偿）。

**教育机构责任（第1199–1201条）**：
- 无民事行为能力人受损害 → 机构承担，能证明尽到教育管理职责的免责（**过错推定**，第1199条）。
- 限制民事行为能力人受损害 → 机构未尽职责担责（**过错责任**，第1200条）。
- 第三人致害由第三人担责，机构未尽管理职责承担**补充责任**（第1201条）。

## 六、特殊侵权各论
**产品责任（第1202–1207条）**：生产者承担**无过错责任**（第1202条）；被侵权人可向**生产者或销售者**请求（不真正连带，第1203条）；投入流通后发现缺陷应停止销售、警示、**召回**，未及时补救就扩大部分担责（第1206条）；**明知缺陷仍生产销售或未有效补救，致死或健康严重损害可请求惩罚性赔偿**（第1207条）。

**机动车交通事故（第1208–1217条）**：
- 租赁借用 → 使用人担责，所有人/管理人有过错相应责任（第1209条）；转让交付未登记 → 受让人担责（第1210条）；**挂靠 → 挂靠人与被挂靠人连带**（第1211条）；盗抢车 → 盗抢人担责（第1215条）；拼装/报废车转让 → 转让人与受让人连带（第1214条）。
- **赔偿顺序（第1213条）**：交强险 → 商业三者险 → 侵权人。
- 逃逸由交强险赔，机动车不明/未投保由**道路交通事故社会救助基金**垫付（可追偿，第1216条）。
- **好意同乘（第1217条）**：非营运机动车无偿搭乘人受损，应减轻使用人责任（故意/重大过失除外）。

**医疗损害（第1218–1228条）**：医疗机构承担**过错责任**（第1218条）；医务人员负**说明与知情同意义务**（手术、特殊检查治疗须取得患者明确同意，第1219条）；紧急情况不能取得意见经负责人批准可立即实施（第1220条）；未尽与当时医疗水平相应的诊疗义务担责（第1221条）。
- **过错推定（第1222条）**：违反法律法规规章及诊疗规范；隐匿/拒绝提供病历；遗失、伪造、篡改、违法销毁病历。
- 药品、消毒产品、医疗器械缺陷或不合格血液，可向**药品上市许可持有人/生产者/血液机构或医疗机构**请求（第1223条）。
- 免责（第1224条）：患者及近亲属不配合（机构也有过错的相应担责）；紧急情况下尽到合理诊疗义务；限于当时医疗水平难以诊疗。
- 应妥善保管病历、保护患者隐私，不得实施**不必要检查**（第1225–1227条）。

**环境污染、生态破坏（第1229–1235条）**：
- 污染环境破坏生态致损承担**无过错责任**（第1229条）；行为人就免责减责情形及**不存在因果关系举证（举证责任倒置）**（第1230条）。
- 故意污染破坏造成严重后果可请求**惩罚性赔偿**（第1232条）；第三人过错，被侵权人可向侵权人或第三人请求（第1233条）。
- 可修复的承担**修复责任**（第1234条）；赔偿范围含服务功能损失、永久损害、调查鉴定费、修复费、防损费用（第1235条）。

**高度危险责任（第1236–1244条）**：均为**无过错责任**，免责事由逐类收紧：
| 情形 | 责任人 | 免责/减责 |
|---|---|---|
| 核设施/核材料事故 | 营运单位 | 战争、武装冲突、暴乱或受害人故意（第1237条） |
| 民用航空器 | 经营者 | 受害人故意（第1238条） |
| 占有使用高度危险物 | 占有人/使用人 | 受害人故意或不可抗力免责；重大过失减轻（第1239条） |
| 高空/高压/地下挖掘/高速轨道运输 | 经营者 | 受害人故意或不可抗力免责；重大过失减轻（第1240条） |
| 遗失抛弃危险物 | 所有人（交他人管理的管理人，所有人有过错连带） | 第1241条 |
| 非法占有危险物 | 非法占有人（所有人管理人未尽高度注意连带） | 第1242条 |
未经许可进入危险区域，管理人证明已采取足够安全措施并尽警示义务可减轻或免责（第1243条）；法定赔偿限额从其规定（故意/重大过失除外，第1244条）。

**饲养动物损害（第1245–1251条）**：饲养人/管理人承担**无过错责任**，能证明损害因被侵权人故意或重大过失可免责/减轻（第1245条）；未采取安全措施仅在受害人**故意**时减轻（第1246条）；**禁止饲养的烈性犬等危险动物致损绝对担责**（第1247条）；动物园承担过错推定（尽管理职责免责，第1248条）；遗弃逃逸期间由**原饲养人/管理人**担责（第1249条）；第三人过错可向饲养人或第三人请求（第1250条）。

**建筑物和物件损害（第1252–1258条）**：
- 倒塌塌陷 → 建设单位与施工单位**连带**（能证明无质量缺陷除外）（第1252条）。
- 脱落坠落 → 所有人/管理人/使用人**过错推定**（第1253条）。
- **高空抛物坠物（第1254条）**：由侵权人担责；经调查难确定具体侵权人的，由**可能加害的建筑物使用人补偿**（能证明不是侵权人的除外，补偿后可向侵权人追偿）；物业未采取必要安保措施担责；公安等应及时调查查清责任人。
- 堆放物、公共道路遗撒、林木折断、地面施工/窨井等均采过错推定（第1255–1258条）。

## 典型示例（study）
- 篮球比赛中正常对抗致你受伤，对方无故意或重大过失 → **自甘风险**，不得请求对方赔偿（第1176条）。
- 小区高空坠物砸伤行人、查不清是谁 → 由可能加害的住户**补偿**（除非能证明事发时不在家等），物业未尽安保义务担责（第1254条）。
- 顾客在商场滑倒（地面湿滑无警示牌）→ 商场未尽**安全保障义务**担责；若因第三人追撞且商场已尽义务，由第三人担责、商场仅在未尽义务时补充（第1198条）。
- 新车自燃致损，消费者可找生产者或销售者赔偿；明知缺陷仍销售致死伤可主张**惩罚性赔偿**（第1203、1207条）。

## 关键提示
1. 先定归责原则：过错（举证在原告）、过错推定/无过错（被告自证）。
2. 多数人侵权：共同/共同危险/累积因果 → 连带；部分因果 → 按份。
3. 自甘风险限于文体活动且排除故意重大过失；自助行为须立即报官。
4. 精神损害须"严重"；惩罚性赔偿限于知识产权、产品、环境三类法定情形。
5. 记住几条无过错责任：监护人、用人单位、产品生产者、环境污染、高度危险、饲养动物；高空抛物难定侵权人时"可能加害人补偿"。
