# 第三编 合同（一）：合同通则（第463–593条）

## 核心要义
合同是设立、变更、终止民事法律关系的协议。通则按合同生命周期展开：**订立 → 效力 → 履行 → 保全 → 变更转让 → 终止 → 违约责任**。婚姻、收养、监护等身份协议优先适用身份法，没有规定的可参照本编（第464条）。

## 一、合同的订立（第469–501条）
**形式（第469条）**：书面、口头或其他；数据电文可有形表现并随时调取的视为书面。一般条款见第470条（当事人、标的、数量、质量、价款、履行、违约责任、争议解决）。

**要约与承诺（第472–489条）**：
| 环节 | 规则 | 条文 |
|---|---|---|
| 要约要件 | 内容具体确定；表明经承诺即受约束 | 472 |
| 要约邀请 | 拍卖/招标公告、招股说明书、基金招募书、商业广告宣传、价目表等；广告内容符合要约条件的构成要约 | 473 |
| 要约撤回 | 撤回通知先于或同时到达（适用第141条） | 475 |
| 要约不得撤销 | 明示不可撤销（如确定承诺期限）；受要约人有理由认为不可撤销且已做履行准备 | 476 |
| 要约失效 | 被拒绝、被撤销、承诺期满未承诺、受要约人作实质性变更 | 478 |
| 承诺生效 | 通知到达时；不需通知的，按交易习惯/要约要求作出行为时；**承诺生效时合同成立** | 483–484 |
| 迟到承诺 | 超期发出为新要约（要约人及时确认有效除外）；按期发出却因其他原因迟到，除要约人及时通知不接受外有效 | 486–487 |
| 实质性变更 | 标的、数量、质量、价款、履行期限地点方式、违约责任、争议解决方法的变更 → 为新要约 | 488 |

**成立时间地点（第490–493条）**：合同书自均签名/盖章/按指印时成立；签字前一方已履行主要义务对方接受的成立（履行治愈）；网购商品/服务，**提交订单成功时合同成立**（第491条）。承诺生效地为成立地，数据电文以收件人主营业地为成立地。

**预约合同（第495条）**：认购书、订购书、预订书等约定将来订约，违约可请求承担预约违约责任。

**格式条款（第496–498条，重点）**：
- 提供方须以合理方式**提示、说明**免除/减轻其责任等重大利害条款；未履行致对方未注意理解的，对方可主张该条款**不成为合同内容**（第496条）。
- **无效（第497条）**：具法定无效情形；不合理免除/减轻己方责任、加重对方责任、限制对方主要权利；排除对方主要权利。
- **解释（第498条）**：按通常理解；两种以上解释作**不利于提供方**的解释；格式与非格式不一致采用非格式条款。

**悬赏（第499条）**：公开声明对完成特定行为者付酬，完成人可请求支付。
**缔约过失责任（第500条）**：恶意磋商、故意隐瞒重要事实或提供虚假情况、其他违背诚信行为，造成对方损失应赔偿。**保密义务（第501条）**：缔约中知悉的商业秘密等，无论合同是否成立不得泄露或不正当使用。

## 二、合同的效力（第502–508条）
- 依法成立的合同自成立时生效（批准等手续从其规定；未办批准不影响报批义务条款效力）（第502条）。
- 无权代理人订约，被代理人已履行或接受履行的视为追认（第503条）；法定代表人/负责人越权订约，除相对人知道或应知越权外**有效**（第504条）；不得仅以超越经营范围认定无效（第505条）。
- **免责条款无效（第506条）**：造成对方**人身损害**的；因**故意或重大过失**造成对方财产损失的。
- 合同不生效/无效/被撤销/终止，**不影响争议解决条款效力**（第507条）。

## 三、合同的履行（第509–534条）
**基本原则**：全面履行 + 诚信附随义务（通知、协助、保密）+ 绿色履行（第509条）。
**约定不明的补救（第510–511条）**：先协议补充 → 按合同条款或交易习惯 → 仍不明：质量按强制国标/推荐国标/行标/通常标准；价款按订立时履行地市场价；履行地点——货币在接受方所在地、不动产在不动产所在地、其他在履行义务方所在地；期限不明可随时履行/请求但给必要准备时间；履行费用由履行义务方负担。

**电子合同交付时间（第512条）**：快递商品以**签收时间**；在线传输交付以进入对方指定特定系统且可检索识别时间。

**选择之债（第515–516条）**：原则上债务人享有选择权，催告后逾期不选转移至对方；通知到达时标的确定。

**多数人之债（第517–521条）**：按份债权/债务（份额不明视为相同）；连带债权/债务（由法律规定或约定）；连带债务人超额清偿可追偿，被追偿人不能履行的其他人按比例分担。

**涉第三人（第522–524条）**：向第三人履行（违约仍向债权人担责；法定/约定第三人可直接请求的，第三人可主张违约责任）；由第三人履行（第三人不履行，债务人担责）；第三人对履行有合法利益的可**代为履行**，债权人接受后债权转让给第三人。

**三大履行抗辩权（重点）**：
| 抗辩权 | 要件 | 效果 | 条文 |
|---|---|---|---|
| 同时履行抗辩 | 互负债务、无先后顺序 | 对方履行前/履行不符约定时可拒绝 | 525 |
| 先履行抗辩 | 有先后顺序，应先履行方未履行/履行不符 | 后履行方可拒绝 | 526 |
| 不安抗辩 | 应先履行方有**确切证据**证明对方经营严重恶化、转移财产抽逃资金、丧失商业信誉等 | 可中止履行并通知；对方提供担保应恢复；合理期限未恢复且未担保可解除并索赔 | 527–528 |

**情势变更（第533条）**：合同基础条件发生订约时无法预见、非商业风险的重大变化，继续履行明显不公平，可请求重新协商，协商不成请求法院/仲裁**变更或解除**。

## 四、合同的保全（第535–542条）
- **代位权（第535–537条）**：债务人怠于行使其债权/从权利影响到期债权实现，债权人可请求以**自己名义代位**行使（专属于债务人自身的除外），范围以到期债权为限；认定成立后由相对人直接向债权人履行。
- **撤销权（第538–539条）**：债务人无偿处分（放弃债权/担保、无偿转让、恶意延长履行期）影响债权实现可撤销；以明显不合理低价转让/高价受让/为他人担保，且**相对人知道或应知**的可撤销。
- 撤销权范围以债权为限；**期间：知道或应知事由起1年，自行为发生起5年消灭**（第541条）；被撤销行为自始无约束力（第542条）。

## 五、合同的变更和转让（第543–556条）
- 协商一致可变更，变更内容不明推定未变更（第543–544条）。
- **债权转让（第545–550条）**：性质/约定/法律不得转让的除外（约定非金钱债权不得转让不得对抗善意第三人，约定金钱债权不得转让不得对抗第三人）；**未通知债务人对债务人不生效**；受让人取得从权利（不因未登记/未占有受影响）；债务人可向受让人主张抗辩及第549条抵销。
- **债务转移（第551–554条）**：须经**债权人同意**（催告后未作表示视为不同意）；新债务人可主张原债务人抗辩。
- **债务加入（第552条）**：第三人表示加入债务，债权人未在合理期限拒绝的，可请求第三人在其愿意承担范围内与债务人承担**连带债务**。
- 权利义务一并转让须经对方同意（第555–556条）。

## 六、合同权利义务终止（第557–576条）
**终止原因（第557条）**：履行、抵销、提存、免除、混同、其他；合同解除亦终止。终止后负后合同义务（通知、协助、保密、旧物回收，第558条）。

**清偿抵充顺序**：
- 数项同种类债务（第560条）：债务人指定 → 已到期 → 担保最少 → 负担较重 → 到期先后 → 比例。
- 费用/利息/本金（第561条）：**实现债权费用 → 利息 → 主债务**。

**合同解除（第562–567条）**：
- 约定解除（协议解除/约定解除事由）。
- **法定解除（第563条）**：不可抗力致不能实现目的；预期违约（明确表示或行为表明不履行主要债务）；迟延履行主要债务经催告合理期限仍未履行；迟延或其他违约致不能实现目的；不定期继续履行合同可随时解除但合理期限前通知。
- **解除权期限（第564条）**：法定/约定，否则自知道或应知解除事由起**1年**，或经催告合理期限不行使消灭。
- 程序：通知到达时解除；异议可请求确认；直接起诉/仲裁的，副本送达时解除（第565条）。
- 后果：未履行终止，已履行可请求恢复原状/补救并索赔；违约解除可主张违约责任；主合同解除担保人原则上仍担责（第566条）；不影响结算清理条款（第567条）。

**抵销（第568–569条）**：互负到期、标的物种类品质相同，通知到达生效，不得附条件期限；种类品质不同经协商一致也可抵销。

**提存（第570–574条）**：债权人无正当理由拒绝受领、下落不明、死亡未确定继承人/遗产管理人或丧失行为能力未确定监护人等可提存；提存后毁损灭失风险、孳息、费用归债权人；**领取权自提存起5年**不行使消灭（扣除费用归国家）。

**免除与混同（第575–576条）**：免除（债务人合理期限拒绝除外）；债权债务同归一人终止（损害第三人除外）。

## 七、违约责任（第577–593条）
**责任形式（第577条）**：继续履行、采取补救措施、赔偿损失等。**预期违约（第578条）**：履行期届满前明确表示或以行为表明不履行，可提前请求担责。
- 金钱债务可请求**继续支付**（第579条）；非金钱债务可请求履行，但法律/事实不能履行、标的不适强制履行或费用过高、债权人合理期限未请求的除外（第580条）；不得强制履行的可请求第三人替代履行费用（第581条）。
- 补救措施：修理、重作、更换、退货、减少价款报酬（第582条）。
- **损害赔偿与可预见规则（第584条）**：赔偿额相当于损失（含可得利益），但不超过违约方订约时**预见或应当预见**的损失。
- **违约金（第585条）**：可约定；低于损失可请求增加，**过分高于损失可请求适当减少**；迟延履行违约金支付后仍须履行。
- **定金（第586–587条）**：实际交付时成立；数额不超过主合同标的额**20%**，超过部分无效；给付方违约无权返还，收受方违约**双倍返还**。
- **违约金与定金竞合（第588条）**：对方可**选择**适用；定金不足弥补损失可请求赔偿差额。
- **不可抗力（第590条）**：按影响部分或全部免责，须及时通知并提供证明；**迟延履行后发生不可抗力不免责**。
- **减损义务（第591条）**：守约方应防止损失扩大，否则不得就扩大部分索赔，合理减损费用由违约方负担。
- 双方违约各自担责；守约方对损失发生有过错可减少赔偿（第592条）；因第三人原因违约仍应向对方担责（第593条）。

## 典型示例（study）
买方付定金10万元（合同总价100万，未超20%）。卖方到期拒不交货：买方可在**双倍返还定金（20万）与违约金条款之间择一**主张（第587–588条）；若实际损失25万且定金不足，可就差额请求赔偿（第588条第2款）。
另：合同签订后遇原材料异常暴涨（非商业风险、订约不可预见）继续履行显失公平，卖方应先与买方协商，不成可请求法院**变更价款或解除**（情势变更，第533条），但不得自行中止，否则承担违约。

## 关键提示
1. 合同成立看承诺生效（网购提交订单）；格式条款未尽提示说明可主张不入合同，歧义作不利于提供方解释。
2. 三大抗辩权中只有不安抗辩权要求"确切证据"，证据不足中止即构成违约。
3. 保全：代位权针对"怠于行使"，撤销权针对"不当处分"（无偿直接撤、有偿须相对人恶意）；期间1年/5年。
4. 债权转让"通知"生效、债务转移"同意"生效、债务加入产生连带。
5. 定金上限20%、收受方违约双倍返还；违约金可增减；不可抗力须通知举证。
