# 第三编 合同（三）：典型合同（下）与准合同（第761–988条）

## 十三类合同速览
| 合同 | 性质/成立 | 核心特征 |
|---|---|---|
| 保理 | 要式（书面）、诺成 | 应收账款转让＋融资/管理/催收/付款担保 |
| 承揽 | 诺成 | 以自己设备技术劳力完成成果，定作人有任意解除权 |
| 建设工程 | 要式（书面） | 主体结构自行完成，禁止转包/再分包，工程价款优先受偿 |
| 运输 | 诺成；公共运输有强制缔约义务 | 客运/货运，承运人对货损承担无过错责任 |
| 技术 | 诺成 | 成果归属与分享是核心；非法垄断/侵害他人成果无效 |
| 保管 | **实践（交付成立）**，可无偿 | 不得使用/转交，注意轻重过失责任差异 |
| 仓储 | **诺成（合意成立）** | 仓单可背书转让，验收后负赔偿责任 |
| 委托 | 诺成，可有偿可无偿 | 处理事务，双方有任意解除权，含隐名代理/披露规则 |
| 物业服务 | 要式（书面） | 前期物业约束业主，不得断水电催费，解聘提前60日 |
| 行纪 | 诺成、有偿 | 行纪人以自己名义、费用自担，有介入权 |
| 中介 | 诺成 | 如实报告，跳单仍应付酬 |
| 合伙 | 诺成 | 共享利益共担风险，人合性强，债务连带 |

## 保理合同（第761–769条）
- 应收账款债权人将现有/将有应收账款转让给保理人（第761条），应书面。
- **虚构应收账款（第763条）**：债权人与债务人虚构的，债务人不得以应收账款不存在对抗保理人（**保理人明知虚构的除外**）。
- 转让通知应表明保理人身份并附凭证（第764条）；债务人接到通知后，债权人与债务人无正当理由变更/终止基础合同对保理人不利的，对保理人不生效（第765条）。
- **有追索权（第766条）**：保理人可向债权人主张返还融资款/回购，也可向债务人主张债权，超额部分返还债权人。**无追索权（第767条）**：向债务人主张，超额无需返还。
- **多重保理顺位（第768条，重点）**：已登记先于未登记；均登记按登记时间先后；均未登记由**最先到达债务人的转让通知**载明者取得；既未登记也未通知按融资款/报酬**比例**取得。

## 承揽合同（第770–787条）
- 包括加工、定作、修理、复制、测试、检验；承揽人应以自己设备、技术、劳力完成**主要工作**（第772条）；主要工作交第三人须经同意，否则定作人可解除，并就第三人成果负责；辅助工作可交第三人但仍负责（第773条）。
- 定作人未付报酬/材料费，承揽人对成果有**留置权**或可拒绝交付（第783条）；共同承揽人原则上连带（第786条）。
- **定作人任意解除权（第787条）**：完成工作前可随时解除，造成损失应赔偿。
- 成果不符质量可请求修理、重作、减少报酬、赔偿（第781条）。

## 建设工程合同（第788–808条）
- 含勘察、设计、施工，应书面；不得支解发包（第791条）。
- **分包规则（重点）**：经发包人同意可分包，第三人与承包人向发包人承担**连带**；不得全部转包、不得支解后变相转包；禁止分包给无资质单位、禁止再分包；**主体结构施工必须承包人自行完成**。
- **合同无效但工程验收合格（第793条）**：可参照合同价款约定**折价补偿**；验收不合格，修复后合格的发包人可请求承包人承担修复费，修复仍不合格的无权请求折价补偿。
- 竣工经验收合格方可交付使用（第799条）；转包、违法分包发包人可解除（第806条）。
- **工程价款优先受偿权（第807条）**：发包人逾期不付，催告后承包人可协议折价或请求法院拍卖，就价款**优先受偿**（不宜折价拍卖的除外）。

## 运输合同（第809–842条）
- 公共运输承运人不得拒绝通常合理的运输要求（第810条）。
- **客运（第823条）**：承运人对运输中旅客伤亡承担赔偿责任（无过错），但伤亡因旅客**自身健康原因**或承运人证明系旅客**故意、重大过失**造成的除外（适用于免票/优待票/经许可搭乘者）。
- **货运（第832条）**：承运人对运输中货物毁损灭失赔偿（无过错），但证明因**不可抗力、货物自然性质或合理损耗、托运人/收货人过错**造成的免责。
- 货物因不可抗力灭失，未收运费不得请求、已收可请求返还（第835条）；不付运费可留置（第836条）；收货人不明/拒收可提存（第837条）。
- 同一方式联运，订约承运人对全程负责，损失区段承运人与订约承运人连带（第834条）。

## 技术合同（第843–887条）
- **职务技术成果（第847条）**：执行工作任务或主要利用单位物质技术条件完成的，使用权、转让权归单位；转让时完成人有优先受让权。非职务成果归个人（第848条）。
- **非法垄断技术或侵害他人技术成果的合同无效**（第850条）。
- **专利申请权归属**：委托开发除另有约定外归**研究开发人**（第859条，委托人可免费/依法实施，转让时委托人优先受让）；合作开发归当事人**共有**（第860条，一方放弃可由他方申请并免费实施，一方不同意申请则他方不得申请）。
- 技术秘密成果无约定的，当事人均有使用和转让权，但研究开发人交付前不得转让第三人（第861条）。
- 转让/许可合同应书面；实施范围不得限制技术竞争和发展（第864条）；后续改进成果无约定的，他方无权分享（第875条）。
- 咨询/服务中受托人利用委托人条件完成的新成果归受托人，委托人利用受托人成果完成的新成果归委托人（第885条）；按咨询报告决策的损失原则上委托人承担（第881条）。

## 保管与仓储
**保管（第888–903条）**：自保管物**交付**成立（第890条）；保管费不明视为**无偿**（第889条）；不得擅自使用或许可使用（第895条）、不得擅自转交第三人（第894条）。
- **赔偿责任（第897条）**：有偿保管保管不善即赔；**无偿保管人证明自己无故意或重大过失即不赔**。
- 贵重物品应**声明**并验收封存，未声明的可按一般物品赔偿（第898条）；不付保管费可留置（第903条）。

**仓储（第904–918条）**：合意即成立（诺成，第905条）；验收后品种数量质量不符的保管人赔偿（第907条）；**仓单经背书并保管人签章可转让提取权**（第910条）；逾期提取加收仓储费、提前提取不减收（第915条）；逾期不提取可提存（第916条）。

## 委托合同（第919–936条）
- 委托人预付费用、偿还垫付款及利息（第921条）；受托人应亲自处理，转委托规则同代理（第923条）。
- **隐名代理（第925条）**：受托人以自己名义在授权内订约，第三人订约时**知道**代理关系的，合同直接约束委托人与第三人。
- **披露规则（第926条）**：第三人不知道代理关系，受托人因第三人原因不履行应向委托人披露第三人，委托人可介入；因委托人原因不履行应向第三人披露委托人，第三人可**选择**受托人或委托人主张权利（选定不得变更）。
- **赔偿责任（第929条）**：有偿委托受托人过错致损即赔；无偿委托仅故意或重大过失致损才赔；越权致损应赔。
- **任意解除（第933条）**：双方均可随时解除；无偿委托解除方赔偿时间不当的直接损失，有偿委托解除方赔偿直接损失及可得利益。

## 物业服务合同（第937–950条）
- 应书面；公开作出的有利业主的服务承诺为合同组成部分（第938条）；**前期物业服务合同对业主有约束力**（第939条）。
- 不得将全部服务转委托或支解后分别转委托（第941条）。
- 已依约提供服务，业主不得以未接受/无需接受为由拒付物业费；**不得采取停止供电供水供热供燃气方式催费**（第944条）。
- 业主共同决定解聘应提前**60日**书面通知（第946条）；物业服务人不同意续聘应提前**90日**通知（第947条）；期满未续聘而继续服务的为不定期，随时解除但提前**60日**通知（第948条）。

## 行纪与中介
**行纪（第951–960条）**：行纪人以**自己名义**为委托人从事贸易，处理事务费用**自行负担**（第952条）；低于指定价卖出/高于指定价买入须经同意，补偿差额后对委托人生效；高卖低买的利益无约定归委托人（第955条）；有市场定价商品行纪人可作为买受人/出卖人（**介入权**，第956条）；与第三人订约直接享有权利承担义务（第958条）；逾期不付报酬可留置（第959条）。

**中介（第961–966条）**：应如实报告，故意隐瞒或提供虚假情况不得请求报酬并赔偿（第962条）；促成合同成立应付报酬，**媒介服务促成的由该合同当事人平均负担**报酬，促成后中介费用自担（第963条）；未促成不得请求报酬但可请求必要费用（第964条）；**委托人"跳单"绕开中介直接订约的仍应付报酬**（第965条）。

## 合伙合同（第967–978条）
- 两个以上合伙人为共同事业共享利益、共担风险；出资及合伙取得财产为**合伙财产，终止前不得请求分割**（第969条）。
- 合伙事务决定原则上**全体一致同意**，可委托部分合伙人执行，其他人有监督权（第970条）。
- **利润分配/亏损分担（第972条）**：约定 → 协商 → 按**实缴出资比例** → 无法确定比例的**平均**。
- 合伙人对合伙债务承担**连带**责任，超额清偿可追偿（第973条）；向外转让份额须其他合伙人一致同意（第974条）；合伙人的债权人**不得代位**行使合伙权利（利益分配请求权除外，第975条）。

## 准合同
**无因管理（第979–984条）**：
- 要件：**没有法定或约定义务**、为避免他人利益受损失而管理他人事务；可请求受益人偿还**必要费用**，管理人受损失可请求适当补偿（第979条）。
- 管理不符合受益人真实意思的不享有权利（但其真实意思违法或违背公序良俗的除外）（第979条第2款）；受益人享有管理利益的在获益范围内担责（第980条）；经事后追认自管理开始时适用委托合同（第984条）。

**不当得利（第985–988条）**：
- 要件：得利人**没有法律根据**取得利益、致他人受损；负返还义务。**除外（第985条）**：为履行道德义务的给付、债务到期前的清偿、明知无给付义务而清偿。
- **善意得利（第986条）**：不知道也不应知无法律根据，且取得利益已不存在的，不承担返还义务。
- **恶意得利（第987条）**：知道或应知无法律根据的，应返还利益并赔偿损失。
- 得利人将利益无偿转让第三人的，受损人可请求第三人在相应范围内返还（第988条）。

## 典型示例（study）
- 甲公司就同一笔应收账款先与乙保理（已登记）后又与丙保理（未登记）→ **乙取得**应收账款（登记先于未登记，第768条）。
- 邻居外出突降暴雨，你雇人帮其修缮漏水屋顶花2000元 → 构成**无因管理**，可请求邻居偿还必要费用（第979条）。
- 银行误转10万元到你账户，你明知后仍花用 → 属**恶意得利**，应返还10万元并赔偿损失（第987条）；若你不知情且钱已被诈骗走、利益不存在 → 善意得利不担返还义务（第986条）。

## 关键提示
1. 保理多重顺位：登记→登记先后→最先通知→比例；虚构账款不得对抗善意保理人。
2. 承揽定作人、委托双方有任意解除权；建设工程主体结构必须自行完成、工程价款优先受偿。
3. 保管是实践合同、仓储是诺成合同；无偿保管/委托仅对故意或重大过失负责。
4. 物业不得断水电催费；解聘60日、不续聘90日；中介跳单仍付酬。
5. 无因管理看"无法定约定义务＋为他人利益"；不当得利区分善意（现存利益）与恶意（返还+赔偿）。
