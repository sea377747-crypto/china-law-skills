# 第四编 人格权（第989–1039条）

## 核心要义
人格权保护**人之为人**的非财产利益，采类型法定＋一般条款（人身自由、人格尊严）双重保护。人格权**不得放弃、转让或继承**（第992条），但姓名、肖像等可许可他人使用（第993条）。

## 一般规定（第990–1001条）
- **权利范围（第990条）**：生命权、身体权、健康权、姓名权、名称权、肖像权、名誉权、荣誉权、隐私权；自然人另享基于人身自由、人格尊严的其他人格权益（一般条款）。
- **死者人格利益（第994条）**：姓名、肖像、名誉、荣誉、隐私、遗体受侵害，由**配偶、子女、父母**请求担责；均无的由其他近亲属请求。
- **不适用诉讼时效（第995条）**：停止侵害、排除妨碍、消除危险、消除影响、恢复名誉、赔礼道歉请求权。
- 违约损害人格权并造成严重精神损害，选择主张违约责任**不影响请求精神损害赔偿**（第996条）。
- **人格权禁令（第997条）**：有证据证明正在/即将实施侵害、不及时制止将造成难以弥补损害的，可申请法院责令停止。
- 认定生命/身体/健康权之外的责任，应考虑职业、影响范围、过错程度、行为目的方式后果（第998条）；为公共利益新闻报道、舆论监督可合理使用，使用不合理仍担责（第999条）。

## 生命权、身体权、健康权（第1002–1011条）
- 生命安全与生命尊严、身体完整与行动自由、身心健康分别受保护；**负有法定救助义务者应及时施救**（第1005条）。
- **人体捐献（第1006条）**：完全行为能力人可**自主、无偿**决定，须书面或遗嘱；生前未拒绝的，死后由配偶、成年子女、父母**共同书面决定**。**禁止买卖人体细胞/组织/器官/遗体，买卖无效**（第1007条）。
- **临床试验（第1008条）**：经主管部门批准＋伦理委员会审查同意＋受试者书面知情同意，**不得向受试者收费**。
- 人体基因、胚胎等医学科研不得危害健康、违背伦理、损害公共利益（第1009条）。
- **性骚扰（第1010条）**：违背意愿以言语、文字、图像、肢体行为实施，受害人可请求担责；机关、企业、学校等单位负预防、受理投诉、调查处置义务。
- 非法剥夺限制行动自由、非法搜查他人身体应担责（第1011条）。

## 姓名权与名称权（第1012–1017条）
- 自然人可决定、使用、变更或许可使用姓名（不得违背公序良俗）；法人、非法人组织的**名称权可转让**（第1012–1013条）。
- 禁止以**干涉、盗用、假冒**方式侵害（第1014条）。
- **姓氏选取（第1015条）**：原则随父或母姓；可选其他直系长辈血亲姓氏、扶养人姓氏或其他不违背公序良俗的正当理由；少数民族遵从本民族习惯。
- 有一定知名度、足以致公众混淆的笔名、艺名、网名、译名、字号、简称参照保护（第1017条）。

## 肖像权（第1018–1023条）
- 肖像是在一定载体上反映的**可识别**的外部形象；可制作、使用、公开或许可使用（第1018条）。
- 不得丑化、污损或利用信息技术**伪造（如 AI 换脸）**；未经同意不得制作、使用、公开（第1019条）。
- **合理使用（第1020条）**：个人学习/艺术欣赏/教学科研必要范围内使用已公开肖像；新闻报道不可避免；国家机关履职必要；展示特定公共环境不可避免；维护公共利益或肖像权人权益。
- 许可条款争议作**有利于肖像权人**解释（第1021条）；期限不明可随时解除，明确期限但肖像权人有正当理由也可解除（第1022条）。
- **自然人声音参照肖像权保护**（第1023条）。

## 名誉权与荣誉权（第1024–1031条）
- 名誉是对品德、声望、才能、信用等的**社会评价**；禁止侮辱、诽谤（第1024条）。
- **新闻报道、舆论监督影响名誉原则上不担责，例外（第1025条）**：捏造歪曲事实；对严重失实内容未尽合理核实义务；使用侮辱性言辞。核实义务的认定因素见第1026条（来源可信度、必要调查、时限性等）。
- **文艺作品（第1027条）**：以特定人为对象含侮辱诽谤内容担责；不以特定人为对象、仅情节相似不担责。
- 报道失实可请求**更正或删除**（第1028条）；可查询信用评价，评价不当可异议请求更正删除（第1029条）。
- 荣誉权：不得非法剥夺荣誉称号、诋毁贬损荣誉（第1031条）。

## 隐私权与个人信息保护（第1032–1039条）
- **隐私（第1032条）**：私人生活安宁及不愿为他人知晓的私密空间、私密活动、私密信息；禁止刺探、侵扰、泄露、公开。
- **禁止行为（第1033条）**：以电话短信即时通讯邮件传单等侵扰生活安宁；进入拍摄窥视住宅/宾馆等私密空间；拍摄窥视窃听公开私密活动；拍摄窥视身体私密部位；处理私密信息等。
- **个人信息（第1034条）**：能单独或结合识别特定自然人的信息——姓名、出生日期、身份证件号、生物识别信息、住址、电话、邮箱、健康信息、行踪信息等；私密信息优先适用隐私权规定。
- **处理规则（第1035条）**：遵循合法、正当、必要、不过度；征得同意（法律另有规定除外）、公开规则、明示目的方式范围。
- **免责（第1036条）**：同意范围内；合理处理自行/合法公开的信息（明确拒绝或侵害重大利益除外）；维护公共利益或本人合法权益。
- 自然人可**查阅、复制、请求更正、删除**其个人信息（第1037条）；处理者不得泄露篡改，未经同意不得非法提供（经加工无法识别且不能复原的除外），负有安全保障与泄露报告义务（第1038条）；国家机关及其工作人员对履职中知悉的隐私和信息负保密义务（第1039条）。

## 典型示例（study）
- 未经同意用 AI 将影视剧片段中演员面部换成本人/他人形象传播 → 侵害**肖像权**（第1019条，信息技术伪造）。
- 商家在小区电梯、通过电话反复向业主推送广告侵扰生活安宁 → 侵害**隐私权（私人生活安宁）**（第1032–1033条）。
- App 超范围收集通讯录、行踪信息且未取得同意 → 违反个人信息处理规则，可要求删除并担责（第1035、1037条）。
- 上司对下属发低俗图文、肢体挑逗，单位接到投诉未处置 → 行为人构成**性骚扰**，单位违反预防处置义务（第1010条）。

## 关键提示
1. 人格权不得放弃转让继承；死者人格利益由近亲属按顺位主张。
2. 记住两项程序性救济：人格权禁令（第997条）、非财产责任请求不适用时效（第995条）。
3. 肖像权核心是"可识别"，合理使用五项法定情形；声音参照肖像保护。
4. 名誉侵权与正当舆论监督的分界看第1025条三项例外。
5. 个人信息处理"同意＋必要＋明示目的"，自然人享有查阅/更正/删除权。
