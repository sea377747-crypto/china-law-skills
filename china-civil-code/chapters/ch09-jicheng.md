# 第六编 继承（第1119–1163条）

## 核心要义
继承解决自然人死亡后遗产的移转。**效力顺位：遗赠扶养协议 ＞ 遗嘱继承/遗赠 ＞ 法定继承**（第1123条）。继承自被继承人**死亡时**开始（第1121条），遗产是死亡时遗留的**个人合法财产**（第1122条）。

## 一般规定（第1120–1125条）
**数人同一事件死亡推定（第1121条）**：相互有继承关系、难定先后的，推定**没有其他继承人的人先死**；都有继承人、辈分不同推定**长辈先死**；辈分相同推定**同时死、互不继承**。

**接受与放弃（第1124条，注意沉默的相反效果）**：
| 主体 | 沉默的后果 | 放弃方式 |
|---|---|---|
| 继承人 | 视为**接受** | 遗产处理前以**书面**表示放弃 |
| 受遗赠人 | 知道受遗赠后**60日**内未表态视为**放弃** | 60日内作出接受/放弃表示 |

**丧失继承权（第1125条）**：①故意杀害被继承人；②为争夺遗产杀害其他继承人；③遗弃或虐待被继承人情节严重；④伪造、篡改、隐匿、销毁遗嘱情节严重；⑤欺诈胁迫迫使/妨碍设立变更撤回遗嘱情节严重。
- 第③–⑤项确有悔改，被继承人表示宽恕或事后遗嘱仍列为继承人的，**不丧失**（宽恕制度）；第①②项为绝对丧失。受遗赠人同样适用。

## 法定继承（第1126–1132条）
继承权男女平等（第1126条）。
**继承顺序（第1127条）**：
- **第一顺序**：配偶、子女、父母。
- **第二顺序**：兄弟姐妹、祖父母、外祖父母。
- 有第一顺序继承人时第二顺序不继承。子女含婚生/非婚生/养子女、有扶养关系的继子女；父母含生父母/养父母、有扶养关系的继父母；兄弟姐妹含同父母、同父异母/同母异父、养、有扶养关系的继兄弟姐妹。

**代位继承（第1128条）**：
- 被继承人子女先死 → 由其**直系晚辈血亲**代位（不受辈数限制）。
- 被继承人兄弟姐妹先死 → 由其**子女**代位。代位继承人只能继承被代位人有权继承的份额。

**丧偶儿媳/女婿（第1129条）**：对公婆/岳父母尽了**主要赡养义务**的，作为第一顺序继承人。

**遗产份额（第1130条）**：同一顺序一般**均等**；对生活特殊困难又缺乏劳动能力者应照顾；尽主要扶养义务或共同生活者可**多分**；有扶养能力条件却不尽义务的应**不分或少分**；协商同意可不均等。
- 第1131条：继承人以外依靠被继承人扶养的人、或对被继承人扶养较多的人，可分给**适当遗产**。

## 遗嘱继承和遗赠（第1133–1144条）
可立遗嘱处分个人财产、指定执行人、设立**遗嘱信托**（第1133条）。

**六种遗嘱形式（重点）**：
| 形式 | 要件 | 条文 |
|---|---|---|
| 自书遗嘱 | 亲笔书写、签名、注明年月日 | 1134 |
| 代书遗嘱 | **2名以上见证人**，一人代书，遗嘱人/代书人/见证人签名注日期 | 1135 |
| 打印遗嘱 | 2名以上见证人，遗嘱人及见证人**每一页签名**注日期 | 1136 |
| 录音录像遗嘱 | 2名以上见证人，记录姓名/肖像及年月日 | 1137 |
| 口头遗嘱 | 危急情况下、2名以上见证人；危急消除后能书面/录音录像立遗嘱的，**口头遗嘱失效** | 1138 |
| 公证遗嘱 | 经公证机构办理 | 1139 |

**见证人禁止（第1140条）**：无/限制行为能力人等无见证能力者；继承人、受遗赠人；与其有利害关系的人。

**必留份（第1141条）**：应为**缺乏劳动能力又没有生活来源**的继承人保留必要份额。
**撤回变更（第1142条）**：可撤回变更，实施与遗嘱相反的行为视为撤回；**数份遗嘱内容抵触以最后所立为准（公证遗嘱不再具有优先效力）**。
**遗嘱无效（第1143条）**：无/限制行为能力人所立；受欺诈胁迫所立；伪造；被篡改部分。
附义务的遗嘱继承/遗赠应履行，无正当理由不履行可请求取消其接受附义务部分遗产的权利（第1144条）。

## 遗产的处理（第1145–1163条）
**遗产管理人（第1145–1149条）**：遗嘱执行人为管理人；无则继承人推选；未推选共同担任；无人继承或均放弃的由生前住所地民政部门或村委会担任。职责：清理遗产制作清单、报告情况、防止毁损、处理债权债务、分割遗产等；故意或重大过失致损担责，可依法/约定获报酬。

**关键规则**：
- **转继承（第1152条）**：继承开始后、遗产分割前继承人死亡且未放弃的，其应继份额转给其继承人（遗嘱另有安排除外）。
- **夫妻共同财产（第1153条）**：分割时先分出**一半**归配偶，其余为遗产；家庭共有财产中先分出他人财产。
- **胎儿份额（第1155条）**：分割时保留胎儿继承份额，娩出为死体的按法定继承处理。
- 法定继承兜底（第1154条）：放弃、丧失继承权/受遗赠权、遗嘱继承人/受遗赠人先死、遗嘱无效部分、未处分遗产。
- 不宜分割的遗产可折价、补偿或共有（第1156条）；再婚一方有权处分所继承财产（第1157条）。

**遗赠扶养协议（第1158条）**：与继承人以外的组织/个人约定由其承担**生养死葬**义务、享有受遗赠权利（效力最优先）。

**债务清偿（限定继承，重点）**：
- 分割遗产应清偿税款债务，但须为缺乏劳动能力又无生活来源者保留必要遗产（第1159条）。
- **继承人以所得遗产实际价值为限**清偿（第1161条），超过部分自愿偿还不限；放弃继承的不负清偿责任。
- 既有法定继承又有遗嘱继承/遗赠的，先由**法定继承人**清偿，超过部分由遗嘱继承人、受遗赠人按所得比例清偿（第1163条）。
- 无人继承又无人受遗赠的归国家（用于公益）；集体所有制组织成员的归该集体（第1160条）。

## 典型示例（study）
- 老人生前与保姆签书面遗赠扶养协议（保姆养老送终获房屋），又立公证遗嘱把房屋给儿子。**遗赠扶养协议效力优先于遗嘱**，房屋归保姆（第1123、1158条）。
- 甲、乙夫妻共同财产200万，甲死亡：先分出100万归乙，剩余100万为甲遗产，由乙及子女等第一顺序继承人分配（第1153条）。
- 继承人书面放弃继承后，对被继承人生前债务可不负清偿责任（第1161条）。

## 关键提示
1. 顺位：遗赠扶养协议 ＞ 遗嘱/遗赠 ＞ 法定继承。
2. 继承人沉默=接受，受遗赠人沉默（60日）=放弃。
3. 法定继承两顺序；代位继承两条线；丧偶儿媳/女婿尽主要赡养可入第一顺序。
4. 遗嘱六形式，除自书/公证外多需2名见证人；数份遗嘱以最后为准（公证不优先）。
5. 清偿以遗产实际价值为限（限定继承），法定继承人先清偿。
