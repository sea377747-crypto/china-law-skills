# 《中华人民共和国民法典》结构化技能

## 概述
本技能将《中华人民共和国民法典》（2020年5月28日第十三届全国人大三次会议通过，自2021年1月1日起施行）结构化为可检索、可适用的知识体系。民法典是"社会生活的百科全书"，共**七编、1260条**：总则、物权、合同、人格权、婚姻家庭、继承、侵权责任。

> 民法典同时废止了原婚姻法、继承法、民法通则、收养法、担保法、合同法、物权法、侵权责任法（第1260条）。

## 何时使用
- 用户询问民法典某一条文、某概念或某制度（如"善意取得的条件""定金罚则""离婚冷静期"）。
- 需要把法律规则适用于具体事实（合同是否有效、谁担责、能否索赔、遗产如何分）。
- 需要请求权基础、构成要件、期间、效力判断、责任形态。
- 不适用：刑法、行政法、诉讼程序法问题；具体个案的裁判预测与正式法律意见（应建议咨询执业律师）。

## 快速开始
1. 先判断问题属于哪一编（见 `cheatsheet.md` 的七编结构）。
2. 高频数字、要件、顺位直接查 `cheatsheet.md`。
3. 术语不清查 `glossary.md`；需要分析框架查 `patterns.md`。
4. 深入某一编时读取对应章节文件。

## 支撑文件
- `glossary.md`：核心术语定义（拼音排序，附条文号）。
- `patterns.md`：10 个通用分析框架（请求权基础、效力判断、公示判断、归责判断等）。
- `cheatsheet.md`：高频年龄、期间、要件、顺位速查。

## 如何使用（按场景）
**场景 A：查条文/概念** → `cheatsheet.md` 定位 → 读对应章节 → 必要时核对原文条文号。
**场景 B：判断合同/行为效力** → 用 `patterns.md` 模式2，先过第143条三要件，再归类无效/可撤销/效力待定。
**场景 C：损害赔偿** → 用模式5定归责原则 → 读 ch10 对应特殊侵权 → 查赔偿范围与免责。
**场景 D：合同纠纷** → 用模式4按生命周期定位 → 读 ch04（及 ch05/ch06 典型合同）。
**场景 E：遗产分配** → 用模式9 → 读 ch09，注意效力顺位与限定继承。
**场景 F：物权归属** → 用模式3看公示 → 读 ch02/ch03，注意善意取得。

## 标准工作流
1. 识别问题类型与所属编。
2. 先查速查表与术语表，再按需读取章节（不要一次性加载全部章节）。
3. 给出结论时**标注条文号**，区分"法律规定"与"分析判断"。
4. 涉及请求时前置检查时效与除斥期间。
5. 事实不清处明确指出需要补充的事实，不作臆断。

## 回答规范
- 优先给结论，再列要件/依据，条文号写在括号内。
- 多用对照表与清单；数字、期间必须与条文一致。
- 对个案说明：本技能提供法律规则与分析，不替代律师意见和法院裁判。

## 来源与核验
- 条文来源：最高人民法院官网公布的《中华人民共和国民法典》全文（court.gov.cn），并与全国人大公布文本一致。
- 已核验第一条至第一千二百六十条齐全（1260 条）。
- 如条文被后续法律或司法解释修订，应以最新官方文本为准。
