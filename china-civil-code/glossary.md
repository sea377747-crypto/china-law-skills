# 术语表（Glossary）

> 按拼音排序；括号内为主要条文号。

**不当得利（985）**：得利人没有法律根据取得利益、致他人受损，负返还义务；分善意（现存利益为限）与恶意（返还并赔偿）。

**不可抗力（180）**：不能预见、不能避免且不能克服的客观情况；按影响部分或全部免责，须及时通知举证。

**诚信原则（7）**：民事主体应秉持诚实、恪守承诺，被誉"帝王条款"，贯穿订约、履行、解释全过程。

**缔约过失（500）**：订立合同中恶意磋商、隐瞒重要事实或提供虚假情况等违背诚信行为，造成对方损失应赔偿。

**代位继承（1128）**：被继承人子女（或兄弟姐妹）先于其死亡，由其直系晚辈血亲（或子女）代位继承相应份额。

**代位权（535）**：债务人怠于行使其债权影响到期债权实现，债权人以自己名义代位行使（专属者除外）。

**担保物权（386）**：为担保债务履行，在债务人不履行时就担保财产优先受偿；含抵押、质押、留置。

**抵押权（394）**：不转移占有，以财产担保；不动产抵押登记设立，动产抵押合同生效设立、登记对抗。

**定金（586）**：担保方式，实际交付成立，数额不超标的额20%；收受方违约双倍返还。

**动产 / 不动产**：物权分类基础；不动产物权变动以登记、动产以交付为公示方式。

**法人（57）**：依法独立享有权利、承担义务，以全部财产独立担责；分营利、非营利、特别法人。

**法定继承（1127）**：无遗嘱/遗赠扶养协议时，按法定顺序（配偶子女父母；兄弟姐妹祖父母外祖父母）继承。

**法律行为（民事法律行为，133）**：通过意思表示设立、变更、终止民事法律关系的行为；有效须满足第143条三要件。

**公平原则（6）**：合理确定各方权利义务；显失公平的行为可撤销。

**共同共有 / 按份共有（297）**：按份共有按份额享有、处分须2/3份额同意；共同共有不分份额、处分须全体同意。

**过错 / 过错推定 / 无过错责任（1165–1166）**：三种归责原则；过错推定与无过错责任须有法律规定。

**合同（464）**：民事主体间设立、变更、终止民事法律关系的协议；身份协议可参照适用合同编。

**居住权（366）**：为满足生活居住，对他人住宅占有使用，原则无偿、登记设立，不得转让继承。

**监护（26）**：对无/限制行为能力人人身财产及合法权益的监督保护；法定、指定、意定等方式。

**留置权（447）**：债权人合法占有债务人动产，债务人不履行可留置并优先受偿（法定担保物权，最优先）。

**民事权利能力（13）**：享有权利、承担义务的资格，始于出生终于死亡。

**民事行为能力（17–24）**：独立实施法律行为的资格，以8周岁、18周岁（16周岁劳动收入视为完全）及辨认能力划分。

**名誉权（1024）**：保护对民事主体品德、声望、才能、信用等的社会评价，禁止侮辱、诽谤。

**隐私权（1032）**：保护私人生活安宁及私密空间、活动、信息，禁止刺探、侵扰、泄露、公开。

**人格权（990）**：生命、身体、健康、姓名（名称）、肖像、名誉、荣誉、隐私等权利，不得放弃转让继承。

**善意取得（311）**：善意、合理价格、已登记/交付三要件具备，受让人取得物权，原权利人向无权处分人索赔。

**诉讼时效（188）**：普通3年、最长20年；法院不得主动适用；中止、中断规则见第194–195条。

**物权（114）**：权利人依法对特定物直接支配和排他的权利，含所有权、用益物权、担保物权，种类内容法定。

**肖像权（1018）**：对可识别的外部形象享有制作、使用、公开或许可使用的权利；声音参照保护。

**质权（425）**：转移占有（动产）或以权利出质担保；动产质权交付设立，权利质权多为登记设立。

**情势变更（533）**：合同基础发生订约不可预见、非商业风险重大变化，继续履行显失公平，可请求变更或解除。

**无因管理（979）**：无法定或约定义务、为他人利益管理事务，可请求偿还必要费用、补偿损失。

**违约金（585）**：约定违约时支付；过低可请求增加、过分过高可请求适当减少。

**遗赠扶养协议（1158）**：扶养人承担生养死葬义务、享有受遗赠权利，效力优先于遗嘱和法定继承。

**用益物权（323）**：对他人之物占有、使用、收益；含土地承包、建设用地、宅基地、居住权、地役权。

**自愿原则（5）**：按自己意思设立、变更、终止法律关系，任何一方不得将意志强加给对方。
